## 步骤

1. 各分支独立开发，仅跑 `:app:compileDebugKotlin` 自检（避免三份全量测试并发）。
2. 主树按 home → editor → chrome 顺序：每个分支先 `git rebase master`，再 `git merge --ff-only`，保持线性历史。
3. core 分支 rebase 到最新 master，补齐 `AppNavHost` 的 `EDITOR_MESSAGE` 接线（调用 home / editor 新增的可选参数）。
4. 主树跑全量 `:app:testDebugUnitTest` + `:app:assembleDebug`；失败就地修复（修复提交到对应分支或 core）。
5. 递增 minor 到 1.15.0，同步 README 版本行与测试数；`assembleRelease`。
6. 发布：`git tag -a v1.15.0`，推送（走本机代理），`gh release create` 附 APK 与 SHA-256。
