## Task A（W1）· 导入/导出可靠性

**改动**

1. `BackupManager.kt`
   - 构造函数新增 `openOutput` / `openInput` 可注入流参数（默认 ContentResolver，签名见 spec「接口冻结」）。
   - `exportZip`：null 流 `error("无法写入所选文件")`；`exportNoteAsTxt(uri, title, content): Boolean`（含标题、null 流 false）。
   - `importZip(uri): BackupImportResult`：条目名白名单、`BackupFormatException`、流式写图、`withTransaction`、分类 name 冲突复用 + `idRemap`、野 `categoryId` 置 null、四类计数。
2. `ImageStore.kt`：新增流式 `writeFile(name, input: InputStream)`（或等价），保持既有 API 不变。
3. `NotesScreen.kt`：`runImport` 用新结果类型与文案；失败区分 `BackupFormatException`；导入确认框补说明；`exporting` / `importing` 状态与菜单/按钮禁用。
4. `NoteEditScreen.kt`：仅把 `exportNoteAsTxt(u, n)` 适配为新签名（`u, n.title, n.content`），不改其它。

**验证**：`.\gradlew :app:testDebugUnitTest --tests "com.mynote.app.data.backup.BackupManagerTest" --tests "com.mynote.app.data.image.ImageStoreTest"` 通过；新增用例覆盖 spec 中列出的断言。
